## Have the prepared files added for you

1. Open [GitHub's new-repository form](https://github.com/new?owner=Aazimashraf17&name=student-performance-regression&description=Student+performance+prediction+using+linear+regression+in+Python+and+R).
2. Choose the visibility you want, turn on **Add a README file**, and create the repository. That initial README creates the first commit needed for a straightforward upload through the connected tools.
3. Return the repository URL in the conversation. The existing README can be replaced with the prepared project README.

## Upload through GitHub yourself

1. Extract `student-performance-regression.zip` on your computer.
2. In the repository, select **Add file → Upload files**.
3. Open the extracted project folder and drag its contents into the upload area. The project README should appear at the repository root. Uploading the ZIP itself leaves the code compressed.
4. Use the commit message `Add Python and R student performance regression project` and commit the files.
5. Inspect the root README and open the `python`, `R`, and `data` directories. If the GitHub Actions workflow was included, open **Actions** to see its first result.

For the simplest assisted route, just create the repository and return its link. You do not need to upload the files manually first.

Official help: [Create a repository](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-new-repository) and [upload files and folders](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository).
